LIVE BUTTON SOUNDBOARD — CHROMEBOOK INSTALL

The app includes:
- Three applause styles plus Tiny Clap
- Sarcastic Clap
- Boo, Laughter, Fog Horn, and Buzzer
- Volume control, overlap mode, Stop All, and keyboard shortcuts 1–9
- Custom sound uploads saved privately on the Chromebook

HOW TO INSTALL
1. Unzip the package.
2. The folder must be placed on a small web host before Chrome can install it.
   Free options include GitHub Pages, Cloudflare Pages, or Netlify Drop.
3. Open the hosted address in Chrome on the Chromebook.
4. Click the Install icon at the right side of Chrome's address bar, or open
   Chrome's three-dot menu and choose “Cast, save, and share” > “Install page as app.”
5. Open Soundboard from the Chromebook launcher. It works offline after the first visit.

ADDING YOUR OWN SOUNDS
Tap “Add your own sounds,” choose one or more audio files, and they will appear
under My sounds. The files stay in this browser on this device.

TIP
For livestreaming, test the Chromebook's audio-sharing option in your streaming
app before going live. Some services require “Share tab audio” or “Share system audio.”
